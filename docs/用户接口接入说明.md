# 用户接口接入说明

## 1. 需要放置的文件

本次用户模块涉及以下后端文件：

- `backend/database.py`
- `backend/models/user.py`
- `backend/crud/user.py`
- `backend/routers/user.py`
- `backend/config/config.py`
- `backend/main.py`

如果你只拷贝新增文件，还需要手动把 `config.py` 和 `main.py` 中的改动合并进去。

## 2. MySQL 配置

后端优先读取完整连接串：

```env
USER_DATABASE_URL=mysql+aiomysql://root:password@127.0.0.1:3306/news_app?charset=utf8mb4
```

如果没有配置 `USER_DATABASE_URL`，会使用下面这些配置拼接：

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=password
MYSQL_DATABASE=news_app
MYSQL_CHARSET=utf8mb4
```

启动前请先在 MySQL 中创建数据库：

```sql
CREATE DATABASE IF NOT EXISTS news_app
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

应用启动时会自动创建 `users` 表。

## 3. 已实现接口

- `POST /api/user/register`
- `POST /api/user/login`
- `GET /api/user/info`
- `PUT /api/v1/user/model-config`

前端鉴权头保持现有约定：

```http
Authorization: <token>
```

不需要加 `Bearer ` 前缀；后端也兼容 `Bearer <token>`。
