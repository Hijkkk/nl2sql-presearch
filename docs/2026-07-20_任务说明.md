## 如何使用 MetadataSummarizer
在 main.py 或其他地方预加载：

```python
from backend.nl2sql.metadata_summarizer import MetadataSummarizer
from backend.nl2sql.sql_generator02 import SQLGenerator

summarizer = MetadataSummarizer()
sql_gen = SQLGenerator()

# 预生成摘要（可选，异步）
meta = adapter.get_metadata()
summarized_meta = await summarizer.summarize_metadata(meta)

# 在生成 SQL 时可传入 summarized_meta（需更新 prompt_builder 支持 summary 字段，或在 format_metadata 中使用 summary）
```
