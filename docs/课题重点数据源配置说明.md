# 课题重点数据源配置说明

## 1. 当前主线

课题重点数据源是：

```text
Hive / Hadoop / MySQL / PostgreSQL / 达梦 / 高斯
```

当前项目的统一架构是：

```text
前端 Vue
  -> FastAPI 后端
    -> DataSourceAdapter 抽象层
      -> SQLiteAdapter
      -> MySQLAdapter
      -> PostgreSQLAdapter
      -> HiveAdapter
      -> DamengAdapter
      -> RESTAPIAdapter（扩展项，不是课题主线）
```

REST API Adapter 只是扩展能力，不是课题主线。后续汇报和计划应优先围绕 Hive/Hadoop、MySQL、PostgreSQL、达梦、高斯展开。

## 3. 为什么 Hadoop 通过 Hive 配置

Hadoop 本身主要是 HDFS/YARN/MapReduce/Spark 等生态，不是一个直接接收 SQL 的关系数据库。

NL2SQL 系统要查询 Hadoop 上的数据，通常通过：

1. HiveServer2
2. Spark SQL Thrift Server
3. Presto / Trino
4. Impala

当前 MVP 选择 HiveServer2，因此配置项叫 `HIVE_QUERY_*`，前端显示为 `Hive数仓`。

## 4. MySQL 配置

```env
MYSQL_QUERY_ENABLED=true
MYSQL_QUERY_NAME=mysql_local
MYSQL_QUERY_HOST=127.0.0.1
MYSQL_QUERY_PORT=3306
MYSQL_QUERY_USER=root
MYSQL_QUERY_PASSWORD=你的密码
MYSQL_QUERY_DATABASE=你的业务库
MYSQL_QUERY_CHARSET=utf8mb4
MYSQL_QUERY_DESCRIPTION=本地 MySQL 业务数据库
```

## 5. PostgreSQL 配置

```env
POSTGRES_QUERY_ENABLED=true
POSTGRES_QUERY_NAME=postgres_local
POSTGRES_QUERY_HOST=127.0.0.1
POSTGRES_QUERY_PORT=5432
POSTGRES_QUERY_USER=postgres
POSTGRES_QUERY_PASSWORD=你的密码
POSTGRES_QUERY_DATABASE=你的数据库
POSTGRES_QUERY_SCHEMA=public
POSTGRES_QUERY_DESCRIPTION=PostgreSQL 业务数据库
```

需要安装：

```text
psycopg2-binary
```

## 6. 高斯配置

高斯常见部署兼容 PostgreSQL 协议，MVP 阶段复用 PostgreSQLAdapter。

```env
GAUSS_QUERY_ENABLED=true
GAUSS_QUERY_NAME=gauss_local
GAUSS_QUERY_HOST=127.0.0.1
GAUSS_QUERY_PORT=5432
GAUSS_QUERY_USER=你的用户
GAUSS_QUERY_PASSWORD=你的密码
GAUSS_QUERY_DATABASE=你的数据库
GAUSS_QUERY_SCHEMA=public
GAUSS_QUERY_DESCRIPTION=高斯数据库业务数据源
```

需要安装：

```text
psycopg2-binary
```

## 7. Hive / Hadoop 配置

```env
HIVE_QUERY_ENABLED=true
HIVE_QUERY_NAME=hive_local
HIVE_QUERY_HOST=127.0.0.1
HIVE_QUERY_PORT=10000
HIVE_QUERY_USER=hive
HIVE_QUERY_PASSWORD=
HIVE_QUERY_DATABASE=default
HIVE_QUERY_AUTH=NOSASL
HIVE_QUERY_DESCRIPTION=Hive/Hadoop 数仓数据源
```

需要安装：

```text
PyHive[hive]
```

## 8. 达梦配置

```env
DAMENG_QUERY_ENABLED=true
DAMENG_QUERY_NAME=dameng_local
DAMENG_QUERY_HOST=127.0.0.1
DAMENG_QUERY_PORT=5236
DAMENG_QUERY_USER=SYSDBA
DAMENG_QUERY_PASSWORD=你的密码
DAMENG_QUERY_SCHEMA=SYSDBA
DAMENG_QUERY_DESCRIPTION=达梦数据库业务数据源
```

需要安装达梦官方 Python 驱动：

```text
dmPython
```

达梦驱动通常来自达梦安装目录或官方驱动包，不一定能直接从公开 pip 源安装。

## 9. 验证方式

启动后端后访问：

```text
GET /api/v1/data-sources
```

启用的数据源会出现在列表中。如果驱动未安装、连接失败或配置错误，状态会返回 `error`，前端会显示连接异常。

查看元数据：

```text
GET /api/v1/metadata/{data_source}
```

聊天查询：

```text
POST /api/v1/chat
```

前端只需要在顶部数据源下拉框切换，不直接接触数据库连接信息。
